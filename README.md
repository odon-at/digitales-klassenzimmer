# digitales-klassenzimmer
An open education project by ODON: a browser-based learning game that teaches students open data, database basics, and how to spot fake/manipulated data using real Austrian open datasets.

## Struktur & Entwicklung

- **`story/`** – Design-Quelle (Spec) für das Spiel. Einstieg: [`story/allgemein.md`](story/allgemein.md).
- **`game/`** – aktuelle Umsetzung (spielbare Web-App). Start/Erweiterung: [`game/README.md`](game/README.md).
- **`releases/`** – eingefrorene, spielbare Versionen (Snapshots).
- **Versionierung** – wie Spec- und Game-Änderungen je Version festgehalten und verglichen werden:
  [`VERSIONING.md`](VERSIONING.md) · Änderungshistorie: [`CHANGELOG.md`](CHANGELOG.md).

Aktuelle Version: **v0.12.0** (siehe `game/js/version.js`).
